# docs/screenshots

Snímky obrazovky použité v hlavním [README.md](../../README.md). Nejsou
součástí živého webu a `index.html` je nikde nenačítá.

Pořízené z lokálně servírovaného webu v Chrome, uložené jako WebP (kvalita 82),
aby repozitář nenabobtnal:

| Soubor | Co zachycuje | Viewport |
| :-- | :-- | :-- |
| `hero.webp` | Hlavička a hero sekce | 1440 × 900 |
| `mega-menu.webp` | Rozbalené mega menu "Služby" | 1440 × 900 |
| `booking.webp` | Rezervace, krok 1: kontaktní údaje | 1440 × 900 |
| `booking-step2.webp` | Rezervace, krok 2: detaily projektu | 1440 × 900 |
| `booking-slots.webp` | Rezervace, krok 3: kalendář a volné časy | 1440 × 900 |
| `audit.webp` | Modal auditu webu, úvodní krok | 1440 × 900 |
| `mobile.webp` | Hero na úzké šířce | 500 × 844 |
| `styleguide.webp` | `design-previews/styleguide.html` | 1440 × 900 |

Snímky s kalendářem ukazují **živá data z cal.com**, takže po nové fotce budou
v README jiné termíny. To je v pořádku, jen ať zůstane vidět, že dostupnost
chodí z API.

Při větší vizuální změně webu je potřeba snímky pořídit znovu, jinak README
ukazuje starý stav.
