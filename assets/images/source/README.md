# assets/images/source

Původní/needitované PNG verze obrázků, ze kterých byly vyrobeny optimalizované
soubory v nadřazené složce (např. `prism-wash-dark.png` → `../prism-wash-dark.jpg`).
Nejsou nikde odkazované z webu — slouží jako zdroj pro budoucí úpravy nebo
znovu-export v jiném formátu/kvalitě.

`prism-wash-light.png` nemá optimalizovaný protějšek na webu — ponechán pro referenci.
