Gradient ve skle

Modrá plocha Profiwebu pod rýhovaným sklem. Rýhy nejsou textura ani obrázek - je to jeden repeating-linear-gradient, kde každá rýha je válcová čočka: světlá na okrajích, tmavší uprostřed. Nad tím může ležet matný panel (backdrop-filter), který rýhy pod sebou rozmaže, jak se chová opravdové matné sklo položené na rýhované.

Plocha
Sklo

Pevná cena předem, žádné měsíce ladění. Ukážeme vám návrh dřív, než se rozhodnete.

Rýhované sklo

Šířka rýhy je jediný knoflík. Sled světlá / tmavá / světlá uvnitř jedné --rib dělá ten válcový tvar; kdyby byl jen jeden přechod, vypadalo by to jako pruhovaná tapeta, ne jako sklo. Druhá, širší a posunutá vrstva rozbíjí pravidelnost. 

.sklo {
  position: absolute; inset: 0; pointer-events: none;
  --rib: clamp(16px, 1.9vw, 30px);
  background:
    repeating-linear-gradient(90deg,
      rgba(255,255,255,.10) 0,
      rgba(255,255,255,.02) calc(var(--rib) * .20),
      rgba(3,14,24,.13)     calc(var(--rib) * .50),
      rgba(255,255,255,.02) calc(var(--rib) * .80),
      rgba(255,255,255,.10) var(--rib)),
    repeating-linear-gradient(90deg,
      rgba(255,255,255,.05) 0,
      rgba(255,255,255,0)   calc(var(--rib) * 1.5),
      rgba(3,14,24,.05)     calc(var(--rib) * 3));
}

Matný panel

backdrop-filter rozostřuje to, co je pod prvkem, takže panel musí ležet nad vrstvou s rýhováním. Vnitřní horní linka (inset 0 1px 0) je odlesk na hraně skla - bez ní panel vypadá jako plochá průsvitná fólie. 

.panel {
  -webkit-backdrop-filter: blur(18px) saturate(1.35);
  backdrop-filter: blur(18px) saturate(1.35);
  background: linear-gradient(150deg, rgba(255,255,255,.16), rgba(255,255,255,.06));
  border: 1px solid rgba(255,255,255,.22);
  box-shadow: 0 20px 50px -24px rgba(3,14,24,.7),
              inset 0 1px 0 rgba(255,255,255,.30);
}
